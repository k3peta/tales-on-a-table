# Tales on a Table — 小さな世界の素材棚

[English](README.en.md) · [简体中文](README.zh-CN.md)

酒場、港町の波止場、ランプ店、骨董屋の小物や家具を、一品ずつ選べる素材棚です。近景はすべて配布BLENDからの実レンダー。気になった形を眺め、置きたい場所や色を考えながら、AIに一品ずつ制作を相談する入口にも使えます。

## ダウンロード

各カテゴリの画像の下にあるZIPリンクを使ってください。ZIPは**GitHub Releases**にあり、このリポジトリの「Code → Download ZIP」には含まれません。各個別ZIPにBLEND・GLB、利用条件、出典と検証情報を収録しています。英語・中国語の説明はこの一覧に掲載し、ZIP内の既存日本語READMEとモデル本体は保持しています。

## 数え方と範囲

**268件 = 単体241件 + グループ25件 + 分離部品2件。** メッシュの数ではありません。同じ対象のBLENDとGLBを二重に数えていません。

酒場56件、波止場56件、ランプ店58件、追加小物5件、骨董屋93件。骨董屋は元の73件と20グループで、AT_091は欠番です。新しい武具屋コレクションは含みません。既存の酒場・ランプ店・骨董屋に含まれる装備品は収録しています。

FT_040・FH_002・FH_038は品質改良版です。追加小物OL_STORY_001〜005はCC0承認済みの版です。IDと数え方を維持しているため、モデルやグループの内訳は各カードで確認してください。

## 使い方

ZIPを展開してBLENDを開くかGLBを対応ソフトに読み込みます。一品を配置してから、必要な物を足して場面を組み立てられます。大きさ・配置・照明の調整が必要で、読み込み先によって材質の見え方も変わります。制作の容易さや同じ結果を保証するものではありません。

モデルに対するCC0表明の範囲は[利用条件](LICENSE.md)と各ZIPをご覧ください。記事・動画・作例画像・完成配置シーンの権利まで許諾するものではありません。完成配置のBLENDは含みません。
