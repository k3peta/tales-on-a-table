### 2026-10-18 JST — 使い方

ZIPを展開してBLENDを開くかGLBを対応ソフトに読み込みます。一品を配置してから、必要な物を足して場面を組み立てられます。大きさ・配置・照明の調整が必要で、読み込み先によって材質の見え方も変わります。制作の容易さや同じ結果を保証するものではありません。
