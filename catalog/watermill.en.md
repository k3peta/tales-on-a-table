25 distribution records / 23 designs. The three sheep poses share one design. WT001–008 are the earlier watermill terrain prototypes, not fully interchangeable with terrain v2.

Each individual ZIP contains BLEND, GLB, README and license terms. CC0 1.0 covers only the model and necessary bundled materials. Articles, example images, arranged scenes and production code are excluded. Some BLEND files are data libraries: use File > Append to load objects or collections. Fine surface details may look different in GLB. In-game performance is untested.
