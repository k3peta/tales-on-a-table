# Tales on a Table — 268条3D素材记录

[日本語](README.md) · [English](README.en.md)

从酒馆、港口码头、灯具店和古董店的道具与家具中，逐件挑选素材。所有近景图均由所提供的BLEND实际渲染。可以先观察一件物品的形状、颜色和使用场景，再用这些具体想法向AI咨询新模型的制作。

## 下载

请使用分类目录中每张图片下方的ZIP链接。模型文件存放在**GitHub Releases**，不包含在“Code → Download ZIP”下载的仓库源码包中。每个独立ZIP含BLEND、GLB、使用条件、来源和验证信息。英文、简体中文说明列于本目录；ZIP内原有的日文README与模型文件保持不变。

## 计数与范围

**268条记录 = 241条模型记录 + 25个组合 + 2个分离部件。** 这不是网格对象数量。BLEND与GLB是同一记录的两种格式，不重复计数。

酒馆56条、码头56条、灯具店58条、追加故事道具5条、古董店93条。古董店由73条原始记录与20个组合构成，AT_091有意留空。不包含新的武具店系列；已获授权的酒馆、灯具店和古董店原有装备仍在其中。

FT_040、FH_002、FH_038保留质量改进版。OL_STORY_001至005保留已获CC0批准的版本。稳定ID和每张卡片的计数单位可区分模型、组合和分离部件。

## 使用方法

解压ZIP后打开BLEND，或在兼容软件中导入GLB。可先摆放一件物品，再逐步添加其他物品来搭建场景。需要调整尺寸、位置和照明，不同软件中的材质外观也可能不同。无法保证制作难易程度或完全一致的结果。

模型专用CC0声明的适用范围见[使用条件](LICENSE.md)及各ZIP。它不延伸至文章、视频、作例图片或完整场景布局。文件中不包含完整场景的BLEND。
