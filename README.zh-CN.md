## 计数与范围

**428条记录 = 397条模型记录 + 26个组合 + 2个分离部件 + 3个结构变体。** 这不是网格对象数量。BLEND与GLB是同一记录的两种格式，不重复计数。

酒馆56条、码头56条、灯具店58条、追加故事道具5条、古董店93条、魔法师书房40条、船长室与船用物品26条、独立家具与陈设6条。古董店由73条原始记录与20个组合构成，AT_091有意留空。另含武具店与仓库系列71条记录；已获授权的酒馆、灯具店和古董店原有装备仍在其中。

FT_040、FH_002、FH_038保留质量改进版。OL_STORY_001至005保留已获CC0批准的版本。稳定ID和每张卡片的计数单位可区分模型、组合和分离部件。

## 使用方法

解压ZIP后打开BLEND，或在兼容软件中导入GLB。可先摆放一件物品，再逐步添加其他物品来搭建场景。需要调整尺寸、位置和照明，不同软件中的材质外观也可能不同。无法保证制作难易程度或完全一致的结果。

模型专用CC0声明的适用范围见[使用条件](LICENSE.md)及各ZIP。它不延伸至文章、视频、作例图片或完整场景布局。文件中不包含完整场景的BLEND。
